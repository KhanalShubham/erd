# Markdown Rendering & Text Formatting Documentation

## 1. Overview & Problem Statement

### 1.1 The Issue
In several educational and conversational panels—most notably the **AI Database Tutor** modal—text content generated by the AI knowledge engine displayed literal Markdown syntax tokens instead of formatted rich text:
- Raw bold markers: `**Primary Key (PK):**`
- Raw headings: `### Primary Key vs. Foreign Key`
- Raw inline code backticks: `` `StudentID = 101` ``
- Literal asterisks and unformatted bullets: `• **Identifies:** ... in its *own* table.`

### 1.2 User Impact
Instead of reading a cleanly styled textbook/notebook with headers, bold emphasis, monospace SQL badges, and indented lists, learners were seeing raw markup symbols, degrading readability and visual professionalism.

---

## 2. Root Cause Analysis

1. **Direct String Interpolation in React**:
   In `src/features/learning/AiTutorModal.tsx`, message content was rendered directly into a standard HTML `<div>`:
   ```tsx
   {/* PREVIOUS FLAWED IMPLEMENTATION */}
   <div className="whitespace-pre-wrap font-sans text-[12.5px]">
     {msg.text}
   </div>
   ```
   Because React treats strings passed to JSX children as plain text literals, the browser rendered the Markdown characters directly.

2. **Absence of a Markdown Parsing Engine**:
   The project lacked a Markdown-to-JSX compiler (`react-markdown`).

3. **Non-Standard Formatting in Knowledge Base**:
   The responses in `src/engine/ai/aiKnowledgeBase.ts` used Unicode bullet characters (`• `) instead of Markdown-standard dashes (`- `) or asterisks (`* `). Standard CommonMark parsers do not recognize `•` as a list item trigger, treating it as regular paragraph text.

---

## 3. Architecture of the Solution

The solution introduces a dedicated, reusable, design-system-aligned rendering layer:

```
┌────────────────────────────────────────────────────────┐
│  AI Knowledge Base / User Input / Scenario Content     │
│  (Markdown text with headings, bold, code, bullets)   │
└──────────────────────────┬─────────────────────────────┘
                           │ raw markdown string
                           ▼
┌────────────────────────────────────────────────────────┐
│  preprocessMarkdown() Pipeline                         │
│  • Normalizes Unicode bullets (•, ●, ○) to "- "        │
│  • Ensures line-breaks before/after headings           │
│  • Normalizes list continuations & CRLF linebreaks     │
└──────────────────────────┬─────────────────────────────┘
                           │ sanitized CommonMark
                           ▼
┌────────────────────────────────────────────────────────┐
│  <ReactMarkdown> Compiler                              │
│  AST Tree Parsing                                      │
└──────────────────────────┬─────────────────────────────┘
                           │ custom component overrides
                           ▼
┌────────────────────────────────────────────────────────┐
│  Custom Design System Elements (<MarkdownRenderer />)   │
│  • <h3>: Retro font-mono header with amber indicator   │
│  • <strong>: Semibold dark/light high-contrast text    │
│  • <code>: Monospace pill badge with border & shadow   │
│  • <ul> / <ol>: Aligned lists with custom markers      │
│  • <pre>: Terminal-style code block container          │
└────────────────────────────────────────────────────────┘
```

## 4. Key Files Created and Modified

### 4.1 New Component: `src/components/common/MarkdownRenderer.tsx`
Provides the central Markdown rendering interface with retro-notebook aesthetic tokens:

```tsx
import React from 'react';
import ReactMarkdown from 'react-markdown';

interface MarkdownRendererProps {
  content: string;
  className?: string;
  isDark?: boolean;
}

function preprocessMarkdown(raw: string): string {
  if (!raw) return '';
  return (
    raw
      .replace(/\r\n/g, '\n')
      .replace(/^[ \t]*[•●○▪]\s*/gm, '- ')
      .replace(/([^\n])\n(#{1,6}\s+)/g, '$1\n\n$2')
      .replace(/^(#{1,6}\s+[^\n]+)\n([^\n#])/gm, '$1\n\n$2')
      .replace(/([^\n\-\*\d\.\s])\n([ \t]*[\-\*]\s+)/g, '$1\n\n$2')
      .replace(/([^\n\-\*\d\.\s])\n([ \t]*\d+\.\s+)/g, '$1\n\n$2')
  );
}

export const MarkdownRenderer: React.FC<MarkdownRendererProps> = ({
  content,
  className = '',
  isDark = false,
}) => {
  const processed = preprocessMarkdown(content);

  return (
    <div className={`markdown-content font-sans leading-relaxed ${isDark ? 'text-zinc-100' : 'text-zinc-800'} ${className}`}>
      <ReactMarkdown
        components={{
          h3: ({ children }) => (
            <h3 className={`text-[13px] font-bold font-mono tracking-wide mt-2.5 mb-1.5 flex items-center gap-1.5 ${isDark ? 'text-yellow-300' : 'text-zinc-950'}`}>
              <span className="w-1.5 h-1.5 rounded-full bg-amber-500 inline-block shrink-0" />
              <span>{children}</span>
            </h3>
          ),
          strong: ({ children }) => (
            <strong className={`font-bold ${isDark ? 'text-white' : 'text-zinc-950'}`}>
              {children}
            </strong>
          ),
          ul: ({ children }) => (
            <ul className={`my-2 space-y-1 pl-4 list-disc list-outside text-[12px] ${isDark ? 'marker:text-yellow-400' : 'marker:text-amber-600'}`}>
              {children}
            </ul>
          ),
          code: ({ children, className: codeClassName, ...props }) => {
            const isMultiLine = typeof children === 'string' && children.includes('\n');
            if (!codeClassName && !isMultiLine) {
              return (
                <code
                  className={`px-1.5 py-0.5 rounded font-mono text-[11px] font-semibold ${
                    isDark
                      ? 'bg-zinc-800 text-yellow-300 border border-zinc-700'
                      : 'bg-zinc-100 text-amber-900 border border-zinc-300 shadow-2xs'
                  }`}
                  {...props}
                >
                  {children}
                </code>
              );
            }
            return <code className={`font-mono text-xs block overflow-x-auto ${codeClassName || ''}`} {...props}>{children}</code>;
          },
        }}
      >
        {processed}
      </ReactMarkdown>
    </div>
  );
};
```

## 5. Developer Guide: How to Use

When adding any new educational cards, AI responses, or diagnostic feedback:

### Basic Text Rendering
```tsx
import { MarkdownRenderer } from '../components/common/MarkdownRenderer';

// In your component:
<MarkdownRenderer content={item.description} />
```

### Dark Mode (e.g. inside dark bubbles or banners)
```tsx
<MarkdownRenderer content={message.text} isDark={true} />
```

### Custom Sizing / Layout Classes
```tsx
<MarkdownRenderer
  content={explanation}
  className="text-xs text-zinc-600 leading-normal"
/>
```

### Supported Markdown Syntax in UI
| Syntax | Rendered Style |
|---|---|
| `### Title` | Monospace retro section header with circular amber pill |
| `**bold text**` | High-contrast bold (`text-zinc-950` or `text-white`) |
| `*italic*` | Slanted serif/sans emphasis |
| `` `column_name` `` | Monospace badge pill with border and background tint |
| `- item` or `• item` | Bullet list item with amber marker |
| `1. item` | Numbered list item with bold monospace index |
| `> blockquote` | Callout block with amber border on left |
